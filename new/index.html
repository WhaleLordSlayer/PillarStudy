The Cultivate data project

The app is only the first thing being built on top of the data.

Explorer, Who’s Speaking, narrative context, related passages, people, places, events, groups, and relationships depend on a structured scripture data layer that has been a major project in its own right.

That foundation is being built around traceable sources and provenance, so useful relationships can be inspected instead of appearing as unexplained claims.

Over time, the goal is to make portions of that work available outside Cultivate so developers, educators, researchers, and the wider scripture-study community can build on it too.

01Connect the sources.

Relationships should point back to evidence in scripture or a documented source.

02Preserve the provenance.

The source behind a connection matters just as much as the connection itself.

03Let people study.

The data layer supplies context and connections. It does not replace scripture study with generated interpretation.

Building scripture-study infrastructure — and a polished app that shows what it can make possible.
