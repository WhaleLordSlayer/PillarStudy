Requesting access

Early Access starts inside Cultivate.

The website does not collect Live requests.

1

Open Cultivate

Sign in to the app on the account you want to use for hosting.

2

Start a Live Session

Choose the Live option from the lesson flow.

3

Request Early Access

Complete the in-app request form shown when you try to host Live.

Hosting is gated during Early Access. Joining a Live session remains part of the participant experience.
